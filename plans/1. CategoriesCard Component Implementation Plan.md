# CategoriesCard Component Implementation Plan

**Created:** 2026-04-27  
**Status:** Ready for Review  
**Project:** HomeFin Frontend

---

## Overview

Create a card-based component that fits alongside `AccountsGrid` on the App.tsx main page. This component will display all existing Categories from the backend API in a grid of visually attractive cards.

---

## Design Goals

- **Distinct from CategoriesCard:** This new component will have a different name and presentation than the existing `CategoriesCard` (which shows aggregated transaction data)
- **Fit alongside AccountsGrid:** Same grid structure as `AccountsGrid`, using the same layout pattern
- **List all Categories:** Fetch and display all categories from backend `/api/categories` endpoint
- **Follow existing best practices:** Adopt patterns used in `AccountsGrid` component

---

## New Component Name

**CategoriesListView**

This name reflects:
- It's a **list-view** component 
- It displays **categories** from backend
- Distinct from existing `CategoriesCard` which shows transaction breakdown

### Proposed File Structure

```
components/
  CategoriesListView/
    - CategoriesListView.tsx     (main component file)
```

**Reasoning:** 
- Naming convention: `<ComponentName>.tsx` for single-file components
- No separate component file needed for a simple sub-component

### Step 3: Create Categories API Hook 

**File:** `src/lib/api.ts` (add to existing file)

```typescript
const api = {
  getCategories: async (): Promise<Array<{
    id: string;
    name: string;
    parent_id: string | null;
    icon_slug: string;
    color_hex: string;
  }>> => {
    const response = await fetch('http://localhost:8000/api/categories');
    const data = await response.json();
    return data.categories || [];
  }
};

export const categories = api;
```

**Note:** CategoriesListView will use this hook
